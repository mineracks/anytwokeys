    One key means no way back

    A single-key vault has exactly one copy of its private key, inside one YubiKey. There is no seed phrase and no backup. If that key is lost, damaged, wiped or its PIN is locked, the funds are gone for good.
    Use it only for amounts you would be willing to lose. For anything else, a 2-of-3 vault survives the loss of a key.
